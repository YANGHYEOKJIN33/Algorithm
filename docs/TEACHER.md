## 1. 화면 구조

| 단원(큰 탭) | 동사 | 한 단원의 모습 |
|---|---|---|
| 0 🏁 시작 | 길 찾기 | 이 수업이 끝나면(완성된 인공지능 맛보기) · 수업 지도 · 화면 사용법 · 펭귄 표 읽기 · 의사코드 읽기 |
| 1 🕸 수집 | 데이터 모으기 | HTML 탐험 · **크롤링 단계 실행** · 예절 O/X · 🐍 실습 |
| 2 🔍 가공 | 문제 찾기 | **결측치 여부·개수·위치 / 사분위수 / 상자그림 단계 실행** · 🐍 실습 |
| 3 🧹 전처리 | 문제 고치기 | **핵심 속성 / 삭제 / dropna / 평균 / 최빈값 / 텍스트 대체 / 크기 맞추기(정규화) 단계 실행** · 🐍 실습 |
| 4 🧩 학습 준비 | 합치고 나누기 | **concat / merge / 분할 단계 실행** · 🐍 실습 |
| 5 🤖 기계학습 | 학습시키기 | 개념 3쪽 + 알고리즘 4종 × (① 아이디어 ② 단계 실행 ③ 🐍 실습) |
| 6 🚀 프로젝트 | 평가하고 만들기 | **모델 평가 단계 실행 + 고쳐 보고 다시 채점** · 정리표 · 이해 확인 10문제 · 프로젝트 안내 |

0단원은 길 찾기(오리엔테이션)이고, 1~6단원의 번호는 0-2쪽 "인공지능 프로젝트 6단계"의 번호와 같습니다.
쪽 번호는 `단원-쪽`(예: 2-3)으로, 학생 화면의 단계 표시 줄과 📚 목차에 같은 번호가 보입니다. 탭 아래 초록 막대는 그 단원의 진도입니다.
(동사는 화면의 탭에 적힌 것이 기준입니다. 단원별 목표 전체와 확인 문제 정답은 [학습 목표표](./OBJECTIVES.md)에 있습니다.)

### 1.1 단원 = 🧭 표지 → 쪽들 → 📝 정리

교과서의 대단원 도입·정리와 같은 틀입니다.

- **🧭 단원 표지**: 생각 열기 질문(학생이 먼저 자기 생각을 고름) · 핵심 아이디어 · **이 단원을 마치면 할 수 있어요**(쪽을 마치면 ✓) ·
  데이터가 들어올 때 → 나갈 때 · 쪽 목록(목표·시간·진도) · 교육과정 성취기준(접혀 있음).
- **📝 단원 정리**: 1분 요약 · **할 수 있어요 스스로 점검**("🤔 아직"이면 그 쪽으로) · 생각 열기 정답 · 확인 문제 3~6개(틀리면 "그 쪽 다시 보기", 처음에 맞힌 수 표시) ·
  🐍 파이썬 한 줄 정리(프로젝트 때 찾아보는 용도) · 핵심 용어.
- 기계학습은 하위 탭이 있어 표지는 [개념] 맨 앞, 정리는 마지막 [단원 정리] 하위 탭에 있습니다.

### 1.2 한 쪽 = 🎯 목표 하나 + ✋ 할 일

레슨 막대(탭 아래)에 늘 같은 자리로 보입니다.

```
 2단원 🔍 가공 — 문제 찾기 │ 표지✓ 2-1 여부 2-2 개수 … 정리                 ← 이전  다음 →
 2-1 결측치 ① 빈칸인지 확인하기  👣 단계 실행 · 약 5분        │ ✋ 할 일          1/3
 🎯 목표 표의 칸마다 빈칸인지 True/False로 표시할 수 있다. 💡 │ ✅ ⏭ 한 단계를 눌러 …
 학습 요소 [결측치] [True / False]                             │ ☐ ⏩ 끝까지 가서 …
                                                               │ ☐ ❓ 확인 문제 맞히기
```

- **🎯 목표**는 "~할 수 있다"로 끝나는 한 문장입니다. 수업 시작 때 "오늘 이 쪽의 목표"로 읽어 주세요. 💡를 누르면 왜 배우는지와 자세한 설명이 나옵니다.
- **학습 요소**는 그 쪽의 핵심 용어이고, 누르면 📖 용어 사전이 열립니다.
- **✋ 할 일**은 학생이 실제로 하면 **저절로 ✅**가 됩니다(한 단계 넘기기, 끝까지 가기, 뒤로 보기, 표의 칸 누르기, k 바꾸기, 문제 풀기, Colab 열기 등).
  다음 쪽으로 가는 것을 막지는 않고, 다 하면 [다음 →]이 반짝입니다. "초록 ✓ 보여 주세요"로 진행을 확인할 수 있습니다.
- **❓ 확인 문제**는 쪽마다 1개입니다. 단계 실행을 끝까지 가면 확인 문제 단추가 흔들려 알려 줍니다.
  틀리면 정답을 바로 보여 주지 않고 "다시 골라 보세요"라고만 합니다(맞혀야 ✅).
- **📝 단원 정리**의 확인 문제는 **모두 맞혀야** 할 일이 끝납니다. 틀리면 정답 대신 [📖 그 쪽 다시 보기]가 나오고,
  같은 문제를 두 번 틀리면 그때 정답과 이유를 보여 줍니다. 보기가 3개라 차례로 눌러도 결국 맞힐 수 있으므로,
  ✅만으로는 이해했는지 알 수 없습니다. 그래서 **처음 고른 답을 따로 기록**합니다(다시 골라도 바뀌지 않음).
- **처음에 맞힘 n/m**: 단원 정리의 확인 문제 상자, 정리 쪽의 "쪽마다의 확인 문제" 줄, 📚 목차의 단원마다 보입니다.
  이것이 이해를 확인하는 근거입니다. ❓ 창에도 "처음 고른 답이 학습 기록에 남아요"라고 적혀 있어 찍기를 줄입니다.
- **📋 내 학습 기록 복사**(📚 목차 맨 위, 마지막 쪽): 단원마다 쪽 진도 · 쪽 확인 문제와 단원 확인 문제를 **처음에 맞힌 수** ·
  할 수 있어요 스스로 점검 결과 · 6-3 이해 확인 점수를 글로 복사합니다. 학급 설문지(구글 설문 등)나 과제 칸에 붙여 넣게 하면
  누가 어느 단원에서 막혔는지 한눈에 보입니다(서버가 없으므로 이 방법으로 걷습니다).
- **📚 목차**에서 모든 단원의 목표·쪽·진도를 한눈에 보고(지금 쪽은 📍), 원하는 쪽으로 바로 갈 수 있습니다.
  [← 이전]·[다음 →]은 단원 경계를 넘어 이어집니다. 화면이 좁으면 레슨 막대의 [▴ 접기]로 그림을 넓게 쓸 수 있습니다.
  진도는 **이 컴퓨터의 이 브라우저에만** 저장됩니다(로그인·서버 없음). 공용 컴퓨터는 수업 뒤 📚 목차 → ↺ 진도 초기화.

**단계 실행 쪽**은 왼쪽에 의사코드, 오른쪽 위에 그림, 오른쪽 아래에 자료구조가 있습니다.
⏭ 한 단계를 누를 때마다 의사코드 한 줄이 파랗게 켜지고, 그 줄의 설명이 펼쳐지며, 그림과 자료구조가 함께 바뀝니다.
수업 중에는 **⏭ 한 단계로 천천히** 넘기며 "이 줄이 무엇을 바꿨나요?"를 묻는 것을 권합니다(그래서 ⏭ 한 단계가 파란 주 단추입니다).

- **🐍 파이썬 같이 보기**: 켜면 의사코드 줄마다 같은 일을 하는 파이썬이 아래에 붙습니다. 파이썬을 아는 학생용.
- **📒 Colab**: 그 쪽 내용의 실습 노트북을 엽니다. 🐍 실습 쪽 맨 위의 **✅ 실습 점검표**를 모두 체크하면 그 쪽의 할 일이 끝납니다.
  점검표의 세 번째 줄은 노트북마다 **선생님께 보여 줄 결과**입니다(예: 01 `df.shape`가 (345, 9), 05 k=3 정확도 0.957).
  학생 화면에서 그 숫자가 보이는지만 확인하면 됩니다(4장 표 참고).
- **📖 용어 · ⓘ**: 정확한 용어와 쉬운 말을 짝지은 사전.

## 3. 쪽별 수업 포인트

쪽 번호는 학생 화면의 단계 표시 줄·📚 목차와 같습니다. 쪽마다의 🎯 목표·✋ 할 일·❓ 정답은 [학습 목표표](./OBJECTIVES.md)에 있습니다.

### 🏁 0단원 시작 — 길 찾기
- **0-1 이 수업이 끝나면**: 처음 차시에는 화면에 띄워 함께 봅니다. 슬라이더로 부리 길이·깊이를 바꾸면 완성된 인공지능이 종을 맞힙니다.
  "이걸 만들려면 무엇이 필요할까?"를 묻고 표지의 생각 열기(데이터)로 이어 가세요.
- **0-2 수업 지도**: 6단계 카드 = 1~6단원. 이후 모든 단원 표지에 같은 흐름 띠가 나와 "지금 어디쯤인지"를 알려 줍니다.
- **0-3 화면 사용법**: 다른 쪽보다 **먼저** 하게 하세요. 🎯 목표 → ✋ 할 일 → ⏭ 한 단계 → ❓ 확인 문제 순서가 모든 쪽에서 같습니다.
- **0-4 펭귄 표 읽기**: 행·열·인덱스·결측치(NaN). **인덱스(0부터)와 펭귄 번호가 다르다**는 점을 꼭 짚어 주세요(2단원에서 자주 헷갈립니다).
- **0-5 의사코드 읽기**: ⏭를 누를 때마다 한 줄씩 실행되고 "최고" 상자의 값이 바뀝니다. 누르기 전에 "다음엔 최고가 몇이 될까?"를 묻기 좋습니다.

### 🕸 1단원 수집
- **1-1 웹 페이지와 HTML**: 표의 칸을 누르면 HTML의 `<td>`가 켜집니다. "사람이 보는 것 ≠ 컴퓨터가 받는 것".
- **1-2 크롤링 단계 실행**: 2쪽짜리 미니 관측소를 긁습니다. 행목록이 **리스트 안의 리스트**로 쌓이는 것, 쪽이 바뀌어도
