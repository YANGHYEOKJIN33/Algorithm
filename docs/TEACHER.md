## 3. 쪽별 수업 포인트

### 🕸 수집
- **웹 페이지와 HTML**: 표의 칸을 누르면 HTML의 `<td>`가 켜집니다. "사람이 보는 것 ≠ 컴퓨터가 받는 것".
- **크롤링 단계 실행**: 2쪽짜리 미니 관측소를 긁습니다. 행목록이 **리스트 안의 리스트**로 쌓이는 것, 쪽이 바뀌어도
  같은 줄(2~8줄)이 되풀이되는 것을 강조하세요. 크롤링한 값은 처음엔 모두 **글자**('3750')라는 점도.
- **예절**: robots.txt, API 우선, `time.sleep`, 개인정보·저작권. 연습 사이트는 마음껏 긁어도 되는 곳임을 알려 주세요.

### 🔍 가공
- **결측치 3쪽**은 "여부(True/False 표) → 개수(True=1을 더함) → 위치(인덱스 목록)"로 이어집니다.
  인덱스(0부터)와 펭귄 번호가 다르다는 점이 자주 헷갈립니다.
- **사분위수**: 13개로 골라 Q1·Q2·Q3가 4·7·10번째 값으로 딱 떨어집니다(판다스와 같은 값).
  "울타리 밖 = 이상치"이지만, **이상치가 꼭 잘못된 값은 아니다**라는 점도 짚어 주세요.
- **상자그림**: "≈ 끊은 축 / 실제 비율로" 단추로 Colab에서 보게 될 납작한 상자를 미리 보여 줄 수 있습니다.

### 🧹 전처리
- **핵심 속성**: 종(색)마다 점이 따로 모이면 좋은 속성. **번호**는 종마다 몰려 있어 좋아 보이지만
  "데이터를 정리한 순서일 뿐"이라 빼야 한다는 점(데이터 누수의 맛보기)이 좋은 토론거리입니다.
- **dropna vs 대체**: 10행 중 4행(40%)을 잃는 것을 보여 준 뒤 평균·최빈값 대체로 넘어가면 동기가 생깁니다.
  채운 값은 **어림값**이라는 한계도 함께.
- **텍스트 대체**: 0·1·2의 크기에 뜻이 없다는 점("젠투가 아델리의 2배가 아니다").

### 🧩 학습 준비
- **concat**: 인덱스가 0,1,2,0,1,2로 겹치는 장면을 멈춰 보여 주세요 → `ignore_index=True`.
- **merge**: 순서가 달라도 번호로 짝을 찾고, 짝 없는 행은 빠집니다(inner).
- **분할**: "문제집(훈련)으로 공부하고 처음 보는 시험(테스트)으로 평가". 섞어도 X와 y의 짝은 유지됩니다.

### 🤖 기계학습
| 알고리즘 | ① 탐험에서 발견할 것 | ② 단계 실행의 핵심 자료구조 |
|---|---|---|
| k-최근접 이웃 | 341번 펭귄: k=1이면 아델리, k=3이면 턱끈. "🎨 영역 색칠"로 k가 경계를 바꾸는 모습 | 거리목록(리스트) → 정렬 → 세기표(사전) |
| 의사결정 트리 | 날개가 짧아도 부리가 길면 턱끈(283번). 트리의 질문 = 그래프의 나눔 선 | 질문 후보표(지니) · 할일 큐 · 트리 |
| 선형 회귀 | 손으로 직선을 맞추며 MSE 줄이기 → "조금씩 고치기"(경사 하강법) | 계산표(dx·dy·dx×dy·dx²) → w, b |
| k-평균 | 처음 중심을 아델리 3마리로 고르면 엉뚱하게 묶임 → 시작이 중요 | 중심표 · 소속목록 · 중심이 지나온 길 |

- **강화학습 맛보기**: 첫 도전은 구멍에 빠지고, 보상이 점수표 Q에 거꾸로 퍼지며 3번째 도전부터 곧장 물고기로 갑니다.
  "정답을 알려 준 사람이 없다"가 핵심입니다.

### 🚀 프로젝트
- **모델 평가**: 6마리 중 5마리(83%). 틀린 163번은 "부리가 짧은 젠투"라 아델리 이웃에 가까웠습니다 → 틀린 예를 보는 습관.
- **프로젝트 안내**: 체크리스트(브라우저에 저장), 주제 예시, 데이터 구하는 곳, 평가 기준 예시가 있습니다.

- 노트북의 값은 사이트와 같습니다: Q1=3450(13마리), 341번 k=3 → 턱끈, 트리 질문 날개 ≤ 203.5 → 부리 ≤ 42.35,
  w=42.35·b=−4240.92, k-평균 3번 되풀이. 단, **전체 데이터**로 바꾸면 결과가 달라질 수 있다는 점(예: 341번이 아델리로)
  도 좋은 수업 거리입니다.
