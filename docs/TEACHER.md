## 1. 화면 구조

| 큰 탭 | 동사 | 한 단원의 모습 |
|---|---|---|
| 🏁 시작 | 길 찾기 | 이 수업이 끝나면(완성된 인공지능 맛보기) · 수업 지도 · 화면 사용법 · 펭귄 표 읽기 · 의사코드 읽기 |
| 1 🕸 수집 | 데이터 모으기 | HTML 탐험 · **크롤링 단계 실행** · 예절 O/X · 🐍 실습 |
| 2 🔍 가공 | 문제 찾기 | **결측치 여부·개수·위치 / 사분위수 / 상자그림 단계 실행** · 🐍 실습 |
| 3 🧹 전처리 | 문제 고치기 | **핵심 속성 / 삭제 / dropna / 평균 / 최빈값 / 텍스트 대체 단계 실행** · 🐍 실습 |
| 4 🧩 학습 준비 | 합치고 나누기 | **concat / merge / 분할 단계 실행** · 🐍 실습 |
| 5 🤖 기계학습 | 학습시키기 | 개념 3쪽 + 알고리즘 4종 × (① 아이디어 ② 단계 실행 ③ 🐍 실습) |
| 6 🚀 프로젝트 | 평가하고 만들기 | **모델 평가 단계 실행** · 정리표 · 퀴즈 10문제 · 프로젝트 안내 |

탭의 번호(1~6)는 시작 화면의 "인공지능 프로젝트 6단계" 번호와 같습니다. 탭 아래 초록 막대는 그 단원의 진도입니다.
(동사는 화면의 탭에 적힌 것이 기준입니다. 단원별 목표 전체는 [학습 목표표](./OBJECTIVES.md)에 있습니다.)

### 1.1 단원 = 🧭 표지 → 쪽들 → 📝 정리

교과서의 대단원 도입·정리와 같은 틀입니다.

- **🧭 단원 표지**: 생각 열기 질문(학생이 먼저 자기 생각을 고름) · 핵심 아이디어 · **이 단원을 마치면 할 수 있어요**(쪽을 마치면 ✓) ·
  데이터가 들어올 때 → 나갈 때 · 쪽 목록(목표·시간·진도) · 교육과정 성취기준(접혀 있음).
- **📝 단원 정리**: 1분 요약 · **할 수 있어요 스스로 점검**("🤔 아직"이면 그 쪽으로) · 생각 열기 정답 · 확인 문제 3개(틀리면 "그 쪽 다시 보기") ·
  🐍 파이썬 한 줄 정리(프로젝트 때 찾아보는 용도) · 핵심 용어.
- 기계학습은 하위 탭이 있어 표지는 [개념] 맨 앞, 정리는 마지막 [단원 정리] 하위 탭에 있습니다.

### 1.2 한 쪽 = 🎯 목표 하나 + ✋ 할 일

레슨 막대(탭 아래)에 늘 같은 자리로 보입니다.

```
 2단원 🔍 가공 — 문제 찾기 │ 표지✓ 2-1 여부 2-2 개수 … 정리                 ← 이전  다음 →
 2-1 결측치 ① 빈칸인지 확인하기  👣 단계 실행 · 약 5분        │ ✋ 할 일          1/3
 🎯 목표 표의 칸마다 빈칸인지 True/False로 표시할 수 있다. 💡 │ ✅ ⏭ 한 단계를 눌러 …
 학습 요소 [결측치] [True / False]                             │ ☐ ⏩ 끝까지 가서 …
                                                               │ ☐ ❓ 확인 문제 맞히기
```

- **🎯 목표**는 "~할 수 있다"로 끝나는 한 문장입니다. 수업 시작 때 "오늘 이 쪽의 목표"로 읽어 주세요. 💡를 누르면 왜 배우는지와 자세한 설명이 나옵니다.
- **학습 요소**는 그 쪽의 핵심 용어이고, 누르면 📖 용어 사전이 열립니다.
- **✋ 할 일**은 학생이 실제로 하면 **저절로 ✅**가 됩니다(한 단계 넘기기, 끝까지 가기, 뒤로 보기, 표의 칸 누르기, k 바꾸기, 문제 풀기, Colab 열기 등).
  다음 쪽으로 가는 것을 막지는 않고, 다 하면 [다음 →]이 반짝입니다. "초록 ✓ 보여 주세요"로 진행을 확인할 수 있습니다.
- **❓ 확인 문제**는 쪽마다 1개입니다. 단계 실행을 끝까지 가면 확인 문제 단추가 흔들려 알려 줍니다.
  틀리면 정답을 바로 보여 주지 않고 "다시 골라 보세요"라고만 합니다(맞혀야 ✅).
- **📝 단원 정리**의 확인 문제는 **모두 맞혀야** 할 일이 끝납니다. 틀리면 정답 대신 [📖 그 쪽 다시 보기]가 나오고,
  같은 문제를 두 번 틀리면 그때 정답과 이유를 보여 줍니다(찍어서 넘어가지 않게).
- **📚 목차**에서 모든 단원의 목표·쪽·진도를 한눈에 보고(지금 쪽은 📍), 원하는 쪽으로 바로 갈 수 있습니다.
  [← 이전]·[다음 →]은 단원 경계를 넘어 이어집니다. 화면이 좁으면 레슨 막대의 [▴ 접기]로 그림을 넓게 쓸 수 있습니다.
  진도는 **이 컴퓨터의 이 브라우저에만** 저장됩니다(로그인·서버 없음). 공용 컴퓨터는 수업 뒤 📚 목차 → ↺ 진도 초기화.

**단계 실행 쪽**은 왼쪽에 의사코드, 오른쪽 위에 그림, 오른쪽 아래에 자료구조가 있습니다.
⏭ 한 단계를 누를 때마다 의사코드 한 줄이 파랗게 켜지고, 그 줄의 설명이 펼쳐지며, 그림과 자료구조가 함께 바뀝니다.
수업 중에는 **⏭ 한 단계로 천천히** 넘기며 "이 줄이 무엇을 바꿨나요?"를 묻는 것을 권합니다(그래서 ⏭ 한 단계가 파란 주 단추입니다).

- **🐍 파이썬 같이 보기**: 켜면 의사코드 줄마다 같은 일을 하는 파이썬이 아래에 붙습니다. 파이썬을 아는 학생용.
- **📒 Colab**: 그 쪽 내용의 실습 노트북을 엽니다. 🐍 실습 쪽 맨 위의 **✅ 실습 점검표**를 모두 체크하면 그 쪽의 할 일이 끝납니다.
- **📖 용어 · ⓘ**: 정확한 용어와 쉬운 말을 짝지은 사전.

## 3. 쪽별 수업 포인트

### 🕸 수집
- **웹 페이지와 HTML**: 표의 칸을 누르면 HTML의 `<td>`가 켜집니다. "사람이 보는 것 ≠ 컴퓨터가 받는 것".
- **크롤링 단계 실행**: 2쪽짜리 미니 관측소를 긁습니다. 행목록이 **리스트 안의 리스트**로 쌓이는 것, 쪽이 바뀌어도
  같은 줄(2~8줄)이 되풀이되는 것을 강조하세요. 크롤링한 값은 처음엔 모두 **글자**('3750')라는 점도.
- **예절**: robots.txt, API 우선, `time.sleep`, 개인정보·저작권. 연습 사이트는 마음껏 긁어도 되는 곳임을 알려 주세요.

### 🔍 가공
- **결측치 3쪽**은 "여부(True/False 표) → 개수(True=1을 더함) → 위치(인덱스 목록)"로 이어집니다.
  인덱스(0부터)와 펭귄 번호가 다르다는 점이 자주 헷갈립니다.
- **사분위수**: 13개로 골라 Q1·Q2·Q3가 4·7·10번째 값으로 딱 떨어집니다(판다스와 같은 값).
  "울타리 밖 = 이상치"이지만, **이상치가 꼭 잘못된 값은 아니다**라는 점도 짚어 주세요.
- **상자그림**: "≈ 끊은 축 / 실제 비율로" 단추로 Colab에서 보게 될 납작한 상자를 미리 보여 줄 수 있습니다.

### 🧹 전처리
- **핵심 속성**: 종(색)마다 점이 따로 모이면 좋은 속성. **번호**는 종마다 몰려 있어 좋아 보이지만
  "데이터를 정리한 순서일 뿐"이라 빼야 한다는 점(데이터 누수의 맛보기)이 좋은 토론거리입니다.
- **dropna vs 대체**: 10행 중 4행(40%)을 잃는 것을 보여 준 뒤 평균·최빈값 대체로 넘어가면 동기가 생깁니다.
  채운 값은 **어림값**이라는 한계도 함께.
- **텍스트 대체**: 0·1·2의 크기에 뜻이 없다는 점("젠투가 아델리의 2배가 아니다").

### 🧩 학습 준비
- **concat**: 인덱스가 0,1,2,0,1,2로 겹치는 장면을 멈춰 보여 주세요 → `ignore_index=True`.
- **merge**: 순서가 달라도 번호로 짝을 찾고, 짝 없는 행은 빠집니다(inner).
- **분할**: "문제집(훈련)으로 공부하고 처음 보는 시험(테스트)으로 평가". 섞어도 X와 y의 짝은 유지됩니다.

### 🤖 기계학습
| 알고리즘 | ① 탐험에서 발견할 것 | ② 단계 실행의 핵심 자료구조 |
|---|---|---|
| k-최근접 이웃 | 341번 펭귄: k=1이면 아델리, k=3이면 턱끈. "🎨 영역 색칠"로 k가 경계를 바꾸는 모습 | 거리목록(리스트) → 정렬 → 세기표(사전) |
| 의사결정 트리 | 날개가 짧아도 부리가 길면 턱끈(283번). 트리의 질문 = 그래프의 나눔 선 | 질문 후보표(지니) · 할일 큐 · 트리 |
| 선형 회귀 | 손으로 직선을 맞추며 MSE 줄이기 → "조금씩 고치기"(경사 하강법) | 계산표(dx·dy·dx×dy·dx²) → w, b |
| k-평균 | 처음 중심을 아델리 3마리로 고르면 엉뚱하게 묶임 → 시작이 중요 | 중심표 · 소속목록 · 중심이 지나온 길 |

- **강화학습 맛보기**: 첫 도전은 구멍에 빠지고, 보상이 점수표 Q에 거꾸로 퍼지며 3번째 도전부터 곧장 물고기로 갑니다.
  "정답을 알려 준 사람이 없다"가 핵심입니다.

### 🚀 프로젝트
- **모델 평가**: 6마리 중 5마리(83%). 틀린 163번은 부리가 짧은 젠투예요. 가장 가까운 161번은 젠투지만 이웃 3마리 중 2마리가 아델리라 다수결에서 졌습니다 → 틀린 예를 보는 습관(🔎 단추로 이웃을 보여 줄 수 있어요).
- **프로젝트 안내**: 체크리스트(브라우저에 저장), 주제 예시, 데이터 구하는 곳, 평가 기준 예시가 있습니다.
