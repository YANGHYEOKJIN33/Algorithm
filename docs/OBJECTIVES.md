3. 의사코드 '최고 ← 5' 다음에 '최고 ← 8'을 실행하면 최고 상자에는? — 정답: **8** (←로 새 값을 넣으면 상자 속 예전 값은 사라져요. 그래서 최고에는 8만 남아요.)
